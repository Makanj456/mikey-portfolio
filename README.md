# mikey-portfolio

Personal portfolio website for Mikey, software engineering and management student at the University of Gothenburg.

Plain HTML, CSS and JavaScript with no build step. Open `index.html` in a browser to preview.

## Editing content
Look for `TODO` comments and `[bracketed placeholders]` in `index.html`.

## Publishing
Settings → Pages → Source: "Deploy from a branch" → `main` / `(root)`. The site will appear at https://makanj456.github.io/mikey-portfolio/.
